# 启明智能客服系统产品手册

## 产品定位

启明智能客服系统是企业级 SaaS 客服平台，面向银行、航空、电商等行业提供多渠道（网页、App、微信、电话）的智能客服解决方案。核心价值是降低人工客服成本、提升响应速度与客户满意度。

## 核心功能

1. 工单系统：客户问题自动生成工单，支持优先级、分派、SLA 计时、超时升级。
2. 知识库问答：内置意图识别与 FAQ 匹配，常见问题自动应答，准确率目标 95%。
3. 人机协同：复杂问题自动转人工，人工可接管会话并查看完整上下文。
4. 满意度评价：会话结束后自动邀请客户打分，纳入质检与模型优化。

## 版本信息

- 当前版本：v3.2.0（2026 年 3 月发布）
- 支持 API：REST / WebSocket / 企业微信回调
- 数据部署：支持私有化部署与公有云 SaaS 两种模式
